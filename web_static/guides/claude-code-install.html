Claude Code 安裝教學：Windows、Mac 一步一步裝好

Claude Code 是 Anthropic 的 AI 編程助手，在終端機裡幫你寫程式、改 bug、做網站。照下面四步，大約 10 分鐘就能裝好。

約 5 分鐘讀完 · 依官方文件整理，2026 年 10 月更新

開始前先確認

  • 電腦：macOS 13 以上，或 Windows 10（1809 版）以上；記憶體 4 GB 以上。
  • 帳號：Claude Pro、Max、Team、Enterprise，或 Console（API）帳號。免費版 Claude 不能用 Claude Code。
  • 網路：要能上網，並且在 Anthropic 支援的國家或地區使用。

第 1 步：打開終端機

Mac：按 ⌘ + 空白鍵，輸入「終端機」（Terminal）後按 Enter。
Windows：按開始鍵，輸入「PowerShell」後打開。不需要用系統管理員身分。

第 2 步：貼上安裝指令

依你的電腦選一行，複製後貼進終端機，按 Enter。

Mac / Linux
curl -fsSL https://claude.ai/install.sh | bash
Windows（PowerShell）
irm https://claude.ai/install.ps1 | iex
Windows（命令提示字元 CMD）
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

Windows 建議另外裝 Git for Windows（可選），這樣 Claude Code 可以用 Bash 執行指令；沒裝也能用，會改用 PowerShell。

第 3 步：確認裝好了

關掉終端機，再開一個新的，輸入：

檢查版本
claude --version

出現版本號（例如 2.1.x (Claude Code)）就是裝好了。想做完整檢查可以再跑：

完整檢查
claude doctor

第 4 步：登入，開始用

先進到你的專案資料夾（例如 cd Desktop/my-project），然後輸入：

啟動
claude

第一次會打開瀏覽器讓你登入 Claude 帳號，登入後回到終端機就能直接用中文下指令，例如「幫我看看這個資料夾裡有什麼」或「幫我做一個記帳的小網頁」。

其他安裝方式

習慣用套件管理工具也可以，但這兩種不會自動更新：

Mac（Homebrew）
brew install --cask claude-code
Windows（WinGet）
winget install Anthropic.ClaudeCode

用 npm 安裝需要 Node.js 22 以上，而且不要加 sudo：

npm
npm install -g @anthropic-ai/claude-code

怎麼更新

用官方安裝指令裝的會在背景自動更新。想立刻更新就輸入 claude update。

常見錯誤

看到的訊息怎麼處理
claude 不是內部或外部命令 / command not found關掉終端機重開一個。還是不行，代表安裝位置沒加進 PATH，跑 claude doctor 看建議。
The token '&&' is not a valid statement separator你在 PowerShell 裡貼了 CMD 的指令，改用 PowerShell 那一行。
'irm' is not recognized你在 CMD 裡貼了 PowerShell 的指令，改用 CMD 那一行。
403、syntax error near unexpected token '<' 或其他 curl 錯誤通常是網路連不到官方伺服器，換個網路再試。

常見問題

Claude Code 要錢嗎？
軟體本身免費安裝，但需要 Claude Pro、Max、Team、Enterprise 或 Console（API）帳號才能使用，免費版 Claude 不行。
一定要會寫程式嗎？
不用。可以直接用中文告訴它你要做什麼，它會自己寫程式、改檔案，每一步做之前會先問你。
Windows 要裝 WSL 嗎？
不用。Claude Code 可以直接在 Windows 上用；如果你的專案本來就在 WSL 裡，也可以在 WSL 裡安裝。
