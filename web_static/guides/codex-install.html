Codex CLI 安裝教學：用 ChatGPT 帳號在電腦上跑 Codex

Codex CLI 是 OpenAI 的 AI 編程助手，在終端機裡讀你的專案、寫程式、跑指令。如果你已經有 ChatGPT 付費方案，就可以直接用。

約 4 分鐘讀完 · 依官方說明整理，2026 年 10 月更新

開始前先確認

  • 帳號：ChatGPT Plus、Pro、Business、Edu 或 Enterprise 方案；也可以改用 OpenAI API key。
  • 電腦：macOS、Linux 或 Windows。

第 1 步：安裝

打開終端機（Mac 是「終端機」，Windows 是 PowerShell），依你的電腦貼上一行：

Mac / Linux
curl -fsSL https://chatgpt.com/codex/install.sh | sh
Windows（PowerShell）
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

習慣用套件管理工具的也可以：

npm
npm install -g @openai/codex
Mac（Homebrew）
brew install --cask codex

第 2 步：登入

關掉終端機再開一個新的，輸入：

啟動
codex

選 Sign in with ChatGPT，在瀏覽器登入你的 ChatGPT 帳號就好。

第 3 步：開始用

先 cd 到你的專案資料夾再輸入 codex，然後直接用中文說你要做什麼，例如「幫我把這個網頁改成手機也好看」。它改檔案或跑指令之前會先問你。

常見問題

Codex CLI 要錢嗎？
軟體免費，但要有 ChatGPT Plus、Pro、Business、Edu 或 Enterprise 方案，或者用 OpenAI API key（按用量付費）。
輸入 codex 說找不到指令？
關掉終端機重開一個新的再試；用 npm 裝的話，確認 npm 的全域安裝資料夾有在 PATH 裡。
