DeepSeek API 申請與接入教學，順便算算到底多便宜

DeepSeek 是好用又便宜的 AI 模型，API 價格只有旗艦模型的十幾分之一。這篇教你申請自己的帳號和 API Key、接進你常用的工具，再把費用壓到最低。大約 15 分鐘。

第 1 步：註冊帳號

打開 platform.deepseek.com（DeepSeek 開放平台，不是聊天 App），用電郵或手機號註冊。

第 2 步：充值

進「充值」頁面儲值一點點，一開始 US$5–10 就很夠用。錢直接付給 DeepSeek，留在你自己的帳號裡；按 token 計費，沒有月費。

第 3 步：建立 API Key

進「API keys」→「建立新的 API Key」，取個名字後馬上複製：它只顯示一次。Key 就像密碼，不要給任何人。

第 4 步：測試

把下面這段貼進終端機，YOUR_API_KEY 換成你的 Key：

終端機（Mac、Linux，或有 curl 的 Windows）
curl https://api.deepseek.com/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"model": "deepseek-flash", "messages": [{"role": "user", "content": "Hello!"}]}'

看到 "content": "Hello! …" 就代表成功了。

第 5 步：接進你的工具

DeepSeek 的 API 跟 OpenAI 的格式一樣，大部分 App、外掛和程式庫都能直接用。工具要你填「OpenAI 相容接口」的地方，這樣填：

設定填什麼
Base URLhttps://api.deepseek.com
API Key你的 Key
模型 Modeldeepseek-flash

用 Python 的話，裝官方的 openai 套件：

Python
from openai import OpenAI

client = OpenAI(api_key="YOUR_API_KEY", base_url="https://api.deepseek.com")
reply = client.chat.completions.create(
    model="deepseek-flash",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(reply.choices[0].message.content)

DeepSeek 接入服務

怎麼更省錢

  • 大量任務放在離峰時段跑。DeepSeek 離峰時段（北京時間深夜）大約半價，確切時間看官網價格頁。
  • 提示詞開頭保持一樣。重複的開頭會自動命中快取，快取的輸入便宜很多。
  • 簡單任務關掉「思考」。deepseek-flash 會先思考再回答，思考也算輸出 token。簡短的問答在請求裡加上 "thinking": {"type": "disabled"}。
  • 請它答短一點。輸出 token 大約是輸入的四倍價錢。

常見問題

DeepSeek API 免費嗎？
不免費。聊天 App 免費，但 API 是按用量從你充值的餘額扣錢。它是最便宜的好用模型之一：每百萬輸入 token 約 US$0.30、輸出約 US$1.20，離峰再半價。
你可以直接賣我 DeepSeek 額度嗎？
不行。DeepSeek 的條款不允許轉賣、共用帳號或 Key。你用自己的帳號、自己充值，我只幫你設定好。
該用哪個模型？
deepseek-flash：2026 年 7 月起 DeepSeek API 的通用模型，聊天、寫作、寫程式都可以。
我的 App 能接嗎？
只要能填「OpenAI 相容」的 Base URL 和 Key 就可以，填 https://api.deepseek.com。
