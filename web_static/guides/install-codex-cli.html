How to install OpenAI Codex CLI

Codex CLI is OpenAI's coding assistant for the terminal. It reads your project, writes code and runs commands. If you already pay for ChatGPT, you can use it today.

4-minute read · Based on the official README, updated October 2026

Before you start

  • Account: a ChatGPT Plus, Pro, Business, Edu or Enterprise plan, or an OpenAI API key.
  • Computer: macOS, Linux or Windows.

Step 1: Install

Open a terminal (Terminal on Mac, PowerShell on Windows) and paste the line for your computer:

Mac / Linux
curl -fsSL https://chatgpt.com/codex/install.sh | sh
Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

Or with a package manager:

npm
npm install -g @openai/codex
Mac (Homebrew)
brew install --cask codex

Step 2: Sign in

Open a new terminal and run:

Start
codex

Choose Sign in with ChatGPT and log in in your browser.

Step 3: Start using it

cd into your project folder, run codex, and say what you want, like "make this page look good on phones". It asks before editing files or running commands.
