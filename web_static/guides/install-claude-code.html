How to install Claude Code on Windows and Mac

Claude Code is Anthropic's AI coding assistant. It works in your terminal, writing code, fixing bugs and building small sites for you. Four steps, about ten minutes.

5-minute read · Based on the official docs, updated October 2026

Before you start

  • Computer: macOS 13+ or Windows 10 (1809)+, with 4 GB of RAM or more.
  • Account: Claude Pro, Max, Team, Enterprise or a Console (API) account. The free Claude plan doesn't include Claude Code.
  • Network: an internet connection, in a country Anthropic supports.

Step 1: Open a terminal

Mac: press ⌘ + Space, type "Terminal" and press Enter.
Windows: open the Start menu, type "PowerShell" and open it. You don't need to run it as Administrator.

Step 2: Paste the install command

Pick the line for your computer, copy it into the terminal and press Enter.

Mac / Linux
curl -fsSL https://claude.ai/install.sh | bash
Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex
Windows (Command Prompt)
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

On Windows, installing Git for Windows is optional but recommended: it lets Claude Code run commands through Bash. Without it, Claude Code uses PowerShell instead.

Step 3: Check it worked

Close the terminal and open a new one, then run:

Check the version
claude --version

If you see a version number such as 2.1.x (Claude Code), you're done. For a full health check, run:

Full check
claude doctor

Step 4: Sign in and start

Go to your project folder (for example cd Desktop/my-project) and run:

Start
claude

The first time, a browser window opens so you can sign in to your Claude account. Then just tell it what you want in plain English, like "what's in this folder?" or "build me a small expense-tracker page".

Other ways to install

Package managers work too, but these two don't update automatically:

Mac (Homebrew)
brew install --cask claude-code
Windows (WinGet)
winget install Anthropic.ClaudeCode

The npm package needs Node.js 22 or later. Don't use sudo:

npm
npm install -g @anthropic-ai/claude-code

Updating

The official installer keeps Claude Code updated in the background. To update right away, run claude update.

Common errors

You seeFix
'claude' is not recognized / command not foundOpen a new terminal. If it still fails, the install folder isn't on your PATH: run claude doctor for the fix.
The token '&&' is not a valid statement separatorYou pasted the CMD command into PowerShell. Use the PowerShell line.
'irm' is not recognizedYou pasted the PowerShell command into CMD. Use the CMD line.
403, syntax error near unexpected token '<', or another curl errorUsually the network can't reach the download server. Try another connection.

FAQ

Is Claude Code free?
Installing it is free, but you need a Claude Pro, Max, Team, Enterprise or Console (API) account to use it. The free Claude plan doesn't include it.
Do I need to know how to code?
No. Describe what you want in plain language; it writes the code and edits files, and asks before each change.
Do I need WSL on Windows?
No. Claude Code runs natively on Windows. If your projects already live in WSL, you can install it there instead.
