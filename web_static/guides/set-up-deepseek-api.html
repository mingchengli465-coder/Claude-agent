How to set up the DeepSeek API, and what it really costs

DeepSeek is a capable AI model whose API costs a fraction of the flagship models'. Here's how to get your own account and API key, connect it to your tools and keep the bill low. About 15 minutes.

6-minute read · Updated October 2026

Step 1: Create an account

Go to platform.deepseek.com (the DeepSeek Open Platform, not the chat app) and sign up with your email or phone.

Step 2: Top up

Open Top up and add a small amount, US$5–10 is plenty to start. The money goes to DeepSeek and stays in your own account; you're billed per token, nothing monthly.

Step 3: Create an API key

Open API keys → Create new API key, give it a name and copy it straight away: it's shown only once. Treat it like a password and never share it.

Step 4: Test it

Paste this in a terminal, with your key in place of YOUR_API_KEY:

Terminal (Mac, Linux, Windows with curl)
curl https://api.deepseek.com/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"model": "deepseek-flash", "messages": [{"role": "user", "content": "Hello!"}]}'

A reply with "content": "Hello! …" means it works.

Step 5: Connect your tools

DeepSeek's API works like OpenAI's, so most apps, plugins and code libraries can use it. Wherever a tool asks for an OpenAI-compatible endpoint, enter:

SettingValue
Base URLhttps://api.deepseek.com
API keyyour key
Modeldeepseek-flash

In Python, with the official openai package:

Python
from openai import OpenAI

client = OpenAI(api_key="YOUR_API_KEY", base_url="https://api.deepseek.com")
reply = client.chat.completions.create(
    model="deepseek-flash",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(reply.choices[0].message.content)

Spend less

  • Run big jobs off-peak. DeepSeek charges about half during its off-peak hours (night-time in Beijing); the exact window is on its pricing page.
  • Keep the start of your prompts the same. DeepSeek caches repeated prompt beginnings automatically, and cached input costs far less.
  • Turn off thinking for simple tasks. deepseek-flash reasons before it answers, which uses output tokens. For short, simple replies add "thinking": {"type": "disabled"} to the request.
  • Ask for shorter answers. Output tokens cost about four times as much as input.

FAQ

Is the DeepSeek API free?
No. The chat app is free, but the API is pay-as-you-go from a balance you top up. It's one of the cheapest capable models: about US$0.30 per million input tokens and US$1.20 per million output tokens, half that off-peak.
Can you sell me DeepSeek credits?
No. DeepSeek's terms don't allow reselling or sharing accounts and keys. You open your own account and top up yourself; I only help you set it up.
Which model should I use?
deepseek-flash, the general model on DeepSeek's API since July 2026, for chat, writing and code.
Does it work with my app?
If the app lets you set an "OpenAI-compatible" base URL and key, yes: use https://api.deepseek.com.
